## 未実装・今後の予定

| 項目 | 理由・予定 |
|---|---|
| 実機テスト (Android / iPhone) | Supabase プロジェクト作成後に実施が必要 (docs/TESTING.md のチェックリスト) |
| 実際の Supabase での結合テスト | この開発環境からは Supabase に接続できないため未実施 |
| Vercel への本番デプロイ | アカウント作成・環境変数設定が必要 (docs/SETUP.md 手順 9) |
| Web Push 通知 | iOS はホーム画面追加後の 16.4 以降のみ対応など制約が大きいため、アプリ内通知を先行。次フェーズで実装予定 |
| 一括 ZIP ダウンロード | 有料プラン機能として予定 |
| 高度な検索・フォトブック | 有料プラン機能として予定 |
| 決済 (Stripe) | `plans` テーブルと上限管理は実装済み。決済連携は未実装 |
| オーナー権限の譲渡 | 未実装 (現状はオーナーは退会不可、削除のみ) |
| Capacitor によるネイティブアプリ化 | Web API のみで実装しているため移行可能。未着手 |
| 運用監視 (エラー収集) | Sentry 等の導入は未実施 (docs/OPERATIONS.md 参照) |
| 利用規約・プライバシーポリシーの確定 | 運営者情報の記入と専門家の確認が必要 |
